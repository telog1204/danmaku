# 弾幕 仕様書

## 概要

画面中央のコアが、組み込み画面で設定した武装に従って自動で弾幕を撃ちます。プレイヤーは弾幕を組み立て、迫ってくる敵を倒し続けます。ステージは終わりのない1つだけのローグライクです。

## ゲームの流れ

- ステージは1つで、終わりなく続きます。時間が経つほど敵が強くなります（速さ・反応の良さ・HP・数・撃つ弾）。
- 一定時間ごとに強敵（ボス）が現れます。倒すと時間が止まり、武装・強化パーツ・エネルギー上限解放パーツなどの中から出た3つの候補のうち、1つを選んで手に入れます。
- コアのHPが0になったらゲームオーバーです。何も持ち越さずに最初からやり直します。

## コア

- 画面中央に固定され、動きません。HPを持ちます。
- 積んだ武装の弾を自動で撃ちます。弾の向きや狙う相手は武装ごとに決まります（「武装」を参照）。

## 開始時の状態

- エネルギー上限は3です。
- 速射砲の基本型に加えて、エネルギー3以下の単装の武装（派生版を含む）からランダムに1つを持って始めます。

## 組み込み画面

- プレイヤーがいつでも開けます。開いている間は時間が止まります。
- **エネルギー**：上限があります。武装はそれぞれエネルギーを使います。一度拾った武装は、合計が上限以内なら同じものをいくつでも積めます。
- **強化パーツ**：持っているだけではエネルギーを使いません。拾った個数まで、積んだ武装1つずつに取り付けられます。元になった系統の武装にだけ付けられます。付けた武装は消費エネルギーが増え、同じ武装に付けるほど増え方が大きくなります（1個目は＋1、2個目は＋2、3個目は＋3…。数値は仮）。

### 画面構成

- 戦闘画面の右上の「組み込み」ボタンで開き、右上の「戻る」ボタンで閉じます。
- 上にエネルギーのゲージと「使用 / 上限」を表示します。
- **左の列「持っている武装」**：タップすると1つ積みます。エネルギーが足りないときは積めず、その行を赤く光らせて「エネルギーが足りません」と表示します。列の下に、まだ付けていない強化パーツの数を系統ごとに表示します。
- **右の列「積んでいる武装」**：積んだ武装を1つずつ1行で並べ、付けた強化パーツの数（＋2 など）と、強化パーツを含めたエネルギーを表示します。タップすると「武装の詳しい画面」を開きます。
- **武装の詳しい画面**：付けている強化パーツ（タップで1つ外す）と、その系統の付けられる強化パーツ（持っている数と、付けたときに増えるエネルギーを表示。タップで1つ付ける）を並べます。強化パーツの説明と、「この武装を外す」ボタンもあります。武装を外すと、付けていた強化パーツは手元に戻ります。
- 一覧が画面に収まらないときは、指でなぞる（マウスでドラッグする）とスクロールします。

## 武装

- 武装は4つの系統に分かれ、系統ごとに複数の派生版があります。派生版はそれぞれ別の武装として扱います。
- この仕様書の「敵」には、敵の弾も含みます。敵の弾のHPはすべて1です。
- 狙う相手：
  - 速射砲の基本型・弾幕型・近接防御型と、誘導兵器の基本型・近接防御型は、敵本体と敵の弾を区別せずに、最も近いものを狙います。
  - それ以外（ビーム砲、攻撃型・決戦型、炸裂弾）は敵本体を優先し、狙える本体がいないときだけ敵の弾を狙います。
- エネルギーの数値はすべて仮のもので、試作で調整します。

### 連装型

- すべての武装（派生版を含む）には、連装型があります。連装型は同じ砲を複数門並べ、同時に撃ちます。
- 連装の段階は系統ごとに次のとおりです。
  - 速射砲：単装 → 2連装 → 3連装 → 4連装
  - ビーム砲：単装 → 2連装 → 3連装
  - 炸裂弾：単装 → 2連装 → 3連装
  - 誘導兵器：単装 → 2連装 → 4連装 → 8連装
- 連装型のエネルギーは、元の武装より高いものの、元の武装を同じ数だけ積むよりは少し安くします。今は「元のエネルギー × 門数 × 0.8」を四捨五入し、連装の段階が1つ上がるごとに最低でも1は増やしています（元のエネルギーが1の武装は、門数分と同じになります）。
- 連装型の撃ち方は、系統ごとに次のとおりです（時間や角度は仮の数値）。
  - **速射砲**：2連装は2門を横に並べて交互に、3連装は3門を横に並べて端から順番に撃ちます。4連装は2連装と同じ2門の並びで交互に撃ち、発射速度は2連装の2倍です。1秒間に出る弾の数は、どれも元の門数倍です。
  - **ビーム砲**：横に並べたまま、撃つたびに端の砲から1門ずつ素早く続けて撃ちます（1門ごとに0.05秒ずらし、狙い直す）。
  - **誘導兵器**：全門が同じ向きに、撃つたびに1門ずつ時間をずらして続けて撃ち出します（1門ごとに0.08秒ずらし、狙い直す）。
  - **炸裂弾**：1門ごとに8度ずつ向きを変えた扇形で、撃つたびに1門ずつ時間をずらして続けて撃ちます（1門ごとに0.1秒ずらす。扇形の中心は撃ち始めたときの狙い）。
- 派生版ごとの細かい数値（扇形の幅、近接防御型の射程、決戦型の威力の倍率など）は、仮の値を `src/common/Config.h` にまとめています。

### 速射砲

- 共通：弾がほんの少しばらけて飛ぶ。敵を貫かない。強化パーツ（貫徹力強化）を付けると、確率で貫くようになる。貫いたあとは威力が下がる。
- 共通：砲は今向いている方向を持ち、狙う相手のほうへ旋回する（1秒間に360度まで。積んだばかりのときは上向き）。弾は向いている方向へ出て、旋回中も撃ち続ける。狙うものがいないときは撃たず、向きもそのまま。コアの上に、向いている方向へ伸びる短い砲身を描く。

| 派生版 | 撃ち方 | エネルギー |
|---|---|---|
| 基本型 | 最も近い敵を狙い撃つ（開始時に持っている） | 1 |
| 弾幕型 | 最も近い敵の方向を中心に、扇形に往復しながら撃つ | 2 |
| 攻撃型 | 敵が多い方向を中心に、扇形に往復しながら撃つ | 2 |
| 近接防御型 | ふだんは撃たずに待ち、近く（150ドット以内）に敵が入った瞬間にそちらへ向き直って撃ち始める。撃ち続けている間はほかの速射砲と同じく旋回し、近くに何もいなくなったらやめる。連射が速い。弾の射程はほかの速射砲と同じ | 2 |

### ビーム砲

- 共通：敵を貫く。貫くたびに威力が下がる。弾が速い。長い尾を持ち、尾を含めた線全体に当たり判定がある。

| 派生版 | 撃ち方 | エネルギー |
|---|---|---|
| 基本型 | 最も近い敵を狙い撃つ。威力は低いが、連射は少し速い | 3 |
| 攻撃型 | 敵が多い方向に向けて撃つ。威力は低いが、連射は少し速い | 3 |
| 決戦型 | HPが最も高い敵を狙い撃つ。威力も連射も標準 | 3 |

### 誘導兵器

- 共通：
  - コアから標的の方向へ撃ち出され、一瞬まっすぐ進んでから追いかけ始める。
  - 曲がる力には限りがあり、敵の動き方によってはまれに避けられる。
  - 弾の速さは標準。敵を貫かない。狙った敵が倒されたら、別の敵を狙い直す。
  - 敵や爆炎に当たると消え、そのときに小さな爆発を起こして、周りの敵・ほかの誘導兵器を巻き込む。

| 派生版 | 撃ち方 | エネルギー |
|---|---|---|
| 基本型 | 最も近い敵を追いかける | 2 |
| 攻撃型 | 敵が多い場所へ向かう。消えるときに比較的大きな爆発を起こす | 3 |
| 近接防御型 | 普段は撃たずに待ち、敵が一定の距離まで近づいたら撃ち出して追いかける | 2 |

### 炸裂弾（三式弾）

- 共通：
  - 狙った位置まで飛ぶか、途中で敵に当たると炸裂する。
  - 直撃したときの威力は極めて高いが、連射はかなり遅い。
  - 炸裂した地点に大きな爆炎を起こす。爆炎は少しの間その場に残り、触れた敵や自分の誘導兵器を誘爆させる。
  - さらに、敵を貫かない小さな破片を、進んでいた方向の前方へ円錐形にまき散らす。

| 派生版 | 撃ち方 | エネルギー |
|---|---|---|
| 基本型 | 敵が多い場所へ飛び、その中心の少し手前で炸裂する | 3 |
| 決戦型 | HPが最も高い敵に直撃させる | 4 |

## 強化パーツ

| 系統 | 強化パーツ | 効果 |
|---|---|---|
| 速射砲 | 威力強化 | 1発の威力が上がる |
| | 連射強化 | 撃つ間隔が短くなる |
| | 収束 | 弾のばらつきが小さくなる |
| | 貫徹力強化 | 当たったとき、確率で貫いて先へ進む。付けるほど確率が上がる |
| ビーム砲 | 威力強化 | 1発の威力が上がる |
| | 連射強化 | 撃つ間隔が短くなる |
| | 貫徹力強化 | 貫くたびに下がる威力の幅が小さくなる |
| 誘導兵器 | 威力強化 | 当たったときの威力が上がる |
| | 連射強化 | 撃つ間隔が短くなる |
| | 誘導力強化 | 曲がる力が上がり、避けられにくくなる |
| | 爆発範囲拡大 | 消えるときの爆発が大きくなる |
| 炸裂弾 | 威力強化 | 直撃・爆炎・破片の威力が上がる |
| | 連射強化 | 撃つ間隔が短くなる |
| | 爆炎範囲拡大 | 炸裂したときの爆炎が大きくなる |
| | 爆炎持続延長 | 爆炎がその場に残る時間が長くなる |
| | 破片増加 | まき散らす破片の数が増える |

効果の大きさ（仮の数値）は `src/common/Config.h` にまとめています。

## 拾うもの

倒した敵が落とし、すべて自動で拾います。落とし物は落ちた場所に少しとどまったあと、コアへ吸い寄せられ、触れると拾われます。拾ったものは画面の上に短く表示します。

- **武装**：まだ持っていない種類が出ます。連装型は、1つ下の段階を持っているときだけ落ちる候補に加わります。
- **強化パーツ**：すでに持っている武装（連装型を含む）が出る代わりに落ちます。種類は、その系統の強化パーツからランダムに決まります。
- **エネルギー上限解放パーツ**：見えない経験値がたまると落ちます。拾うとエネルギー上限が1増えます。

落ち方（数値は仮）：

- 敵を倒すと経験値がたまります（1体につき1、回避型は2）。最初は10たまるとエネルギー上限解放パーツが1つ落ち、1つ落ちるたびに次に必要な量が5ずつ増えます。
- 敵を倒したとき、10%の確率で武装か強化パーツを落とします。落ちる候補（すべての単装の武装と、持っている武装の1つ上の連装段階）から武装をランダムに1つ選び、まだ持っていなければその武装、持っていればその系統の強化パーツになります。

敵の弾を消しても、経験値も落とし物も出ません。

## 敵

- 画面の四辺のどこからでも現れます。
- 弾を見て避けるAIです。動きには偶然の要素も入ります。
- 航空機のように動きます。常に機首の向きへ進み、向きは少しずつしか変えられません。止まることも、後ろへ下がることもできず、Uターンするには大きく旋回します。弾を避けるときは、機体を傾けて弧を描くように曲がってかわします。
- 画面に一度入った敵は、端に近づくと旋回して内側へ戻ります。
- コアに近づいてきたり、離れながら弾を撃ってきたりします。
- 時間が経つにつれて、敵の数・HP・速さ・撃つ弾が少しずつ増えていきます。

| 敵 | 動き |
|---|---|
| 突撃型 | コアへまっすぐ近づき、体当たりする。弾は撃たない |
| 射撃型 | コアから一定の距離を保ち、弾を撃ってくる |
| 回避型 | 弾を避けるのが上手く、離れながら撃ってくる |
| 重装型 | 動きは遅いがHPが高く、弾を多くばらまく |
| 群れ型 | 1体ずつは弱いが、大勢でまとまって来る |
| 強敵（ボス） | 一定時間ごとに現れる。はじめは重装型を大きく強くした形にする |

### 強敵

- 強敵がいない時間が一定（仮に60秒）続くと現れます。1体いる間は、次の強敵は現れません。現れる少し前（仮に3秒前）から、画面の上に「強敵接近」と点滅させて知らせます。
- 大きな四角の形で、航空機のようにゆっくり旋回しながらコアの周りを回り、コアの方向へ扇形に弾をばらまきます。HPがとても高く、時間が経つほど高くなります。いる間は、画面の上の中央にHPを表示します。
- コアに体当たりしても消えず、少し間をおいて何度でもダメージを与えます。
- 強敵がいる間も、普通の敵は現れ続けます。
- 倒しても普通の落とし物は落としません。代わりに時間が止まり、報酬を選ぶ画面で3つの候補から1つを選びます。
  - まだ持っていない武装があれば、候補の1つは必ず武装にします。
  - 残りは、持っている武装の系統の強化パーツと、エネルギー上限解放パーツから選びます。同じものは2つ並べません。
- 数値（仮）は `src/common/Config.h` にまとめています。

## 画面の流れとスコア

- 起動するとタイトル画面が出ます。どこかをタップ（クリック）すると、ゲームが始まります。タイトル画面には最高記録を表示します（まだ遊んでいなければ出しません）。
- コアのHPが0になると、戦闘画面を暗くした上に結果（生存時間・倒した敵の数・倒した強敵の数）を出します。
  - 「もう一度」で最初からやり直し、「タイトルへ」でタイトル画面に戻ります。ゲームオーバーの直後（0.5秒）は、うっかり押すのを防ぐため押せません。
- スコアは「生存時間」と「倒した敵の数」です。倒した敵の数には、強敵と、体当たりで消えた敵は含めません。
- 最高記録（生存時間と倒した敵の数）は、ゲームオーバーのたびに保存します。どちらかが最高記録を超えたら「新記録！」と出します（初めて遊んだときは出しません）。
- 保存場所は、Windows版は実行ファイルのあるフォルダ、Android版はアプリ専用の保存場所です（`records.txt`）。

## 操作

- 観戦中は、ボタンをタップ（クリック）して組み込み画面を開きます。
- 組み込み画面では、タップで積んだり、詳しい画面を開いたりします。一覧は指でなぞってスクロールします。

## 見た目

- コアや敵、弾は、丸・三角・四角・線などの図形だけで描きます。加算合成（重なると明るくなる描き方）で光らせます。
